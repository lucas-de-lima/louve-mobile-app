# Project Vocabulary — Louve App

| Term | Definition |
|------|------------|
| Hino | A hymn from the Harpa Cristã collection |
| Harpa Cristã | Brazilian Christian hymnbook, 640 hymns |
| LouveApp | Application class, Hilt entry point |
| MainActivity | Single Activity, Compose host |
| NavGraph | Navigation graph definition |
| Themes | 3 themes: Padrão Claro, Escuro, Sweet Candy |
| LouveThemeData | Theme data class (colors, typography, backgrounds) |
| Favoritos | Favorites system (hybrid local/cloud) |
| Firebase Auth | Authentication provider |
| Firestore | Cloud database |
| DataStore | Local preferences (Jetpack) |
| DataMigrationService | Migrates local data to cloud after login |
| BidirectionalSyncService | Syncs data between devices |
| ConnectivityMonitorService | Monitors network state |
