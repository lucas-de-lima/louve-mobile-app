## 🎨 **VISÃO GERAL DO SISTEMA**

O sistema de temas dinâmicos do Louve App é uma arquitetura robusta e escalável que permite aos usuários personalizar completamente a experiência visual do aplicativo. Ele foi projetado seguindo os princípios de **Clean Architecture** e **Material Design 3**, oferecendo:

- **Temas Dinâmicos**: Múltiplos temas com fundos personalizados
- **Renderização Otimizada**: Fundo centralizado para melhor performance
- **Extensibilidade**: Fácil adição de novos temas
- **Persistência**: Configurações salvas localmente e sincronizadas na nuvem
- **Preview Visual**: Seleção de temas com preview em tempo real

## 🏗️ **ARQUITETURA DOS TEMAS**

### **Estrutura de Arquivos**

```
ui/theme/
├── LouveThemeData.kt          # Definições de dados dos temas
├── AppThemes.kt               # Catálogo de temas disponíveis
├── Theme.kt                   # Motor de aplicação dos temas
├── Color.kt                   # Paletas de cores base
├── Type.kt                    # Tipografia
└── THEMING_DOCS.md           # Documentação técnica detalhada
```

### **Componentes Principais**

#### 1. **LouveThemeData** - O DNA do Tema
```kotlin
data class LouveThemeData(
    val id: String,                    // Identificador único
    val name: String,                  // Nome exibido ao usuário
    val category: ThemeCategory,       // Categoria (Light/Dark/Custom)
    val colors: ColorScheme,           // Paleta Material 3
    val typography: Typography,        // Tipografia
    val backgrounds: LouveBackgrounds, // Fundos personalizados
    val isDefault: Boolean = false     // Tema padrão
)
```

#### 2. **ThemeCategory** - Classificação dos Temas
```kotlin
sealed class ThemeCategory {
    object Light : ThemeCategory()     // Temas claros
    object Dark : ThemeCategory()      // Temas escuros
    object Custom : ThemeCategory()    // Temas personalizados
}
```

#### 3. **LouveBackgrounds** - Fundos Contextuais
```kotlin
data class LouveBackgrounds(
    val screenBackground: @Composable () -> Unit,      // Fundo principal
    val detailScreenBackground: @Composable () -> Unit // Fundo imersivo
)
```

```
    ↓

    ↓
```

```
    ↓
Tela atualizada automaticamente
```

## 🚀 **GUIA COMPLETO PARA CRIAR NOVOS TEMAS**

### **Passo 1: Definir a Paleta de Cores**

Crie uma nova paleta seguindo o Material Design 3:

```kotlin
// Em AppThemes.kt
private val OceanBlueColors = lightColorScheme(
    primary = Color(0xFF1976D2),           // Azul oceano
    onPrimary = Color.White,
    secondary = Color(0xFF42A5F5),         // Azul claro
    onSecondary = Color(0xFF0D47A1),
    tertiary = Color(0xFF81C784),          // Verde água
    onTertiary = Color(0xFF1B5E20),
    background = Color(0xFFF5F5F5),        // Cinza muito claro
    onBackground = Color(0xFF212121),
    surface = Color.White,
    onSurface = Color(0xFF212121),
    surfaceVariant = Color(0xFFE3F2FD),    // Azul muito claro
    onSurfaceVariant = Color(0xFF1976D2),
    outline = Color(0xFFBDBDBD)
)
```

### **Passo 2: Criar os Fundos Personalizados**

#### **Fundo Principal (screenBackground)**
```kotlin
@Composable
private fun OceanBlueBackground() {
    Box(
        modifier = Modifier
            .fillMaxSize()
            .background(
                Brush.verticalGradient(
                    colors = listOf(
                        Color(0xFFE3F2FD),  // Topo: azul muito claro
                        Color(0xFFBBDEFB),  // Meio: azul claro
                        Color(0xFF90CAF9)   // Base: azul médio
                    ),
                    startY = 0f,
                    endY = Float.POSITIVE_INFINITY
                )
            )
    ) {}
}
```

#### **Fundo Imersivo (detailScreenBackground)**
```kotlin
@Composable
private fun OceanBlueDetailBackground() {
    Box(
        modifier = Modifier
            .fillMaxSize()
            .background(
                Brush.radialGradient(
                    colors = listOf(
                        Color.White,
                        Color(0xFFE3F2FD).copy(alpha = 0.8f),
                        Color(0xFFBBDEFB).copy(alpha = 0.6f)
                    ),
                    radius = 800f,
                    center = Offset(0f, 0f)
                )
            )
    ) {}
}
```

### **Passo 3: Definir o Tema Completo**

```kotlin
val OceanBlueTheme = LouveThemeData(
    id = "ocean_blue",
    name = "Azul Oceano",
    category = ThemeCategory.Custom,
    colors = OceanBlueColors,
    typography = Typography,
    backgrounds = LouveBackgrounds(
        screenBackground = { OceanBlueBackground() },
        detailScreenBackground = { OceanBlueDetailBackground() }
    )
)
```

## ✨ **EXEMPLOS DE TEMAS AVANÇADOS**

### **Tema com Animação**
```kotlin
@Composable
private fun AnimatedSunsetBackground() {
    var animationProgress by remember { mutableStateOf(0f) }
    
    LaunchedEffect(Unit) {
        animate(
            initialValue = 0f,
            targetValue = 1f,
            animationSpec = infiniteRepeatable(
                animation = tween(5000, easing = LinearEasing),
                repeatMode = RepeatMode.Reverse
            )
        ) { value, _ ->
            animationProgress = value
        }
    }
    
    Box(
        modifier = Modifier
            .fillMaxSize()
            .background(
                Brush.verticalGradient(
                    colors = listOf(
                        Color(0xFFFF9800).copy(alpha = 0.8f + animationProgress * 0.2f),
                        Color(0xFFE91E63).copy(alpha = 0.6f + animationProgress * 0.4f),
                        Color(0xFF9C27B0).copy(alpha = 0.4f + animationProgress * 0.6f)
                    )
                )
            )
    ) {}
}
```

### **Tema com Padrões Geométricos**
```kotlin
@Composable
private fun GeometricPatternBackground() {
    Canvas(modifier = Modifier.fillMaxSize()) {
        val width = size.width
        val height = size.height
        
        // Desenhar triângulos sobrepostos
        repeat(20) { index ->
            val path = Path().apply {
                moveTo(
                    x = (index * 50f) % width,
                    y = (index * 30f) % height
                )
                lineTo(
                    x = ((index * 50f) + 100f) % width,
                    y = ((index * 30f) + 80f) % height
                )
                lineTo(
                    x = (index * 50f) % width,
                    y = ((index * 30f) + 160f) % height
                )
                close()
            }
            
            drawPath(
                path = path,
                brush = Brush.radialGradient(
                    colors = listOf(
                        Color(0xFF4CAF50).copy(alpha = 0.3f),
                        Color(0xFF4CAF50).copy(alpha = 0.1f)
                    )
                )
            )
        }
    }
}
```

## 📱 **MELHORES PRÁTICAS**

### **1. Design de Cores**
- ✅ **Use o Material Design 3** como base
- ✅ **Mantenha contraste adequado** para acessibilidade
- ✅ **Teste em temas claro e escuro** se aplicável
- ❌ **Evite cores muito vibrantes** que cansem a vista

### **2. Performance**
- ✅ **Use `remember`** para fundos complexos
- ✅ **Evite animações contínuas** em fundos principais
- ✅ **Otimize gradientes** com cores limitadas
- ❌ **Não recrie fundos** a cada recomposição

### **3. Acessibilidade**
- ✅ **Contraste mínimo 4.5:1** para texto
- ✅ **Teste com leitores de tela**
- ✅ **Considere daltonismo** na escolha das cores
- ❌ **Não dependa apenas da cor** para transmitir informação

### **4. Consistência**
- ✅ **Mantenha padrões visuais** consistentes
- ✅ **Use espaçamentos** padronizados
- ✅ **Respeite hierarquia** visual estabelecida
- ❌ **Não quebre convenções** existentes

## 🔧 **TROUBLESHOOTING**

### **Problema: Tema não é aplicado**
**Solução:**
1. Verifique se o tema foi adicionado à lista `AllThemes`
2. Confirme se o `id` é único
3. Verifique se não há erros de compilação

### **Problema: Fundo não aparece**
**Solução:**
1. Confirme se `LouveTheme.backgrounds.screenBackground()` está sendo chamado
2. Verifique se as telas têm `containerColor = Color.Transparent`
3. Confirme se não há fundos duplicados

### **Problema: Performance degradada**
**Solução:**
1. Use `remember` para fundos complexos
2. Simplifique gradientes com muitas cores
3. Evite animações contínuas desnecessárias

### **Problema: Cores não contrastam bem**
**Solução:**
1. Use ferramentas de contraste online
2. Teste com simuladores de daltonismo
3. Ajuste alpha values para melhor legibilidade
