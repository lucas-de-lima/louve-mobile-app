## 🎨 **VISÃO GERAL DO SISTEMA**

O sistema de temas dinâmicos do Louve App é uma arquitetura robusta e escalável que permite aos usuários personalizar completamente a experiência visual do aplicativo. Ele foi projetado seguindo os princípios de **Clean Architecture** e **Material Design 3**, oferecendo:

- **Temas Dinâmicos**: Múltiplos temas com fundos personalizados
- **Renderização Otimizada**: Fundo centralizado para melhor performance
- **Extensibilidade**: Fácil adição de novos temas
- **Persistência**: Configurações salvas localmente e sincronizadas na nuvem
- **Preview Visual**: Seleção de temas com preview em tempo real

### **Componentes Principais**

#### 1. **LouveThemeData** - O DNA do Tema
```kotlin
data class LouveThemeData(
    val id: String,                    // Identificador único
    val name: String,                  // Nome exibido ao usuário
    val category: ThemeCategory,       // Categoria (Light/Dark/Custom)
    val colors: ColorScheme,           // Paleta Material 3
    val typography: Typography,        // Tipografia
    val backgrounds: LouveBackgrounds, // Fundos personalizados
    val isDefault: Boolean = false     // Tema padrão
)
```

#### 2. **ThemeCategory** - Classificação dos Temas
```kotlin
sealed class ThemeCategory {
    object Light : ThemeCategory()     // Temas claros
    object Dark : ThemeCategory()      // Temas escuros
    object Custom : ThemeCategory()    // Temas personalizados
}
```

#### 3. **LouveBackgrounds** - Fundos Contextuais
```kotlin
data class LouveBackgrounds(
    val screenBackground: @Composable () -> Unit,      // Fundo principal
    val detailScreenBackground: @Composable () -> Unit // Fundo imersivo
)
```

### **📋 Passo 1: Planejamento e Identidade Visual**

Antes de começar a codificar, defina:

- **🎯 Identidade Visual**: Que sensação o tema deve transmitir?
- **🌈 Paleta Base**: 3-5 cores principais que definem o tema
- **📱 Categoria**: Light (claro), Dark (escuro) ou Custom (personalizado)
- **💡 Inspiração**: De onde vem a ideia? (natureza, arte, música, etc.)

**Exemplo de Planejamento:**
```
Tema: "Ocean Blue"
Identidade: Calmo, profissional, confiável
Paleta: Azul oceano, azul claro, azul accent, branco areia, texto escuro
Categoria: Custom
Inspiração: Oceano profundo e calmo
```

### **🎨 Passo 2: Definir a Paleta de Cores**

Crie uma nova paleta seguindo o Material Design 3:

```kotlin
// Em AppThemes.kt

// --- Paleta Ocean Blue ---
private val OceanBlue = Color(0xFF1E3A8A)        // Azul principal
private val OceanLight = Color(0xFF3B82F6)       // Azul claro
private val OceanAccent = Color(0xFF06B6D4)      // Azul accent
private val SandWhite = Color(0xFFFEFEFE)        // Branco areia
private val DeepText = Color(0xFF1F2937)         // Texto escuro

private val OceanBlueColors = lightColorScheme(
    primary = OceanBlue,           // Cor principal
    onPrimary = SandWhite,         // Texto sobre cor principal
    primaryContainer = Color(0xFF3B82F6), onPrimaryContainer = SandWhite,  // ⚠️ OBRIGATÓRIO
    secondary = OceanLight,        // Cor secundária
    onSecondary = SandWhite,       // Texto sobre cor secundária
    secondaryContainer = Color(0xFF60A5FA), onSecondaryContainer = SandWhite,  // ⚠️ OBRIGATÓRIO
    tertiary = OceanAccent,        // Cor terciária
    onTertiary = SandWhite,        // Texto sobre cor terciária
    tertiaryContainer = Color(0xFF22D3EE), onTertiaryContainer = DeepText,  // ⚠️ OBRIGATÓRIO
    background = SandWhite,        // Fundo principal
    onBackground = DeepText,       // Texto sobre fundo
    surface = SandWhite,           // Superfície
    onSurface = DeepText,          // Texto sobre superfície
    surfaceVariant = Color(0xFFE3F2FD),    // Variação da superfície
    onSurfaceVariant = DeepText,   // Texto sobre variação
    outline = Color(0xFFCBD5E1)    // Contorno
)
```

### **⚠️ CORES DE CONTAINER OBRIGATÓRIAS**

**IMPORTANTE**: Sempre defina as cores de container para garantir que componentes como números de hinos, botões e cards se adaptem corretamente ao tema:

```kotlin
// ✅ SEMPRE incluir estas cores em todos os temas:
primaryContainer = Color(0xFF...), onPrimaryContainer = Color(0xFF...)
secondaryContainer = Color(0xFF...), onSecondaryContainer = Color(0xFF...)
tertiaryContainer = Color(0xFF...), onTertiaryContainer = Color(0xFF...)
```

**Por que são obrigatórias?**
- **Números de hinos**: Usam `primaryContainer` e `onPrimaryContainer`
- **Botões de ação**: Usam `primaryContainer` para fundo
- **Cards especiais**: Usam `secondaryContainer` para destaque
- **Indicadores**: Usam `tertiaryContainer` para elementos terciários

**Sem essas cores**: O Material Design usa valores padrão (tema branco), causando inconsistência visual.

### **🎯 COMPONENTES QUE USAM CORES DE CONTAINER**

**Lista completa de componentes que dependem das cores de container:**

```kotlin
// 📱 HymnCardItem.kt - Números de hinos
Box(
    modifier = Modifier
        .background(MaterialTheme.colorScheme.primaryContainer)
) {
    Text(
        color = MaterialTheme.colorScheme.onPrimaryContainer
    )
}

// 🔘 Botões de compartilhar
Button(
    colors = ButtonDefaults.buttonColors(
        containerColor = MaterialTheme.colorScheme.primary,
        contentColor = MaterialTheme.colorScheme.onPrimary
    )
)

// 🎨 Cards de tema (seletor)
Card(
    colors = CardDefaults.cardColors(
        containerColor = MaterialTheme.colorScheme.primaryContainer
    )
)
```

**Dica**: Sempre teste esses componentes ao criar novos temas!

### **🖼️ Passo 3: Criar os Fundos Personalizados**

#### **Fundo Principal (screenBackground)**
```kotlin
@Composable
private fun OceanBlueBackground() {
    Box(
        modifier = Modifier
            .fillMaxSize()
            .background(
                Brush.verticalGradient(
                    colors = listOf(
                        OceanLight.copy(alpha = 0.1f),   // Topo: azul claro suave
                        OceanBlue.copy(alpha = 0.15f),   // Meio: azul principal suave
                        OceanAccent.copy(alpha = 0.1f)   // Base: azul accent suave
                    ),
                    startY = 0f,
                    endY = Float.POSITIVE_INFINITY
                )
            )
    ) {}
}
```

#### **Fundo Imersivo (detailScreenBackground)**
```kotlin
@Composable
private fun OceanBlueDetailBackground() {
    Box(
        modifier = Modifier
            .fillMaxSize()
            .background(
                Brush.radialGradient(
                    colors = listOf(
                        Color.White,
                        Color(0xFFE3F2FD).copy(alpha = 0.8f),
                        Color(0xFFBBDEFB).copy(alpha = 0.6f)
                    ),
                    radius = 800f,
                    center = Offset(0f, 0f)
                )
            )
    ) {}
}
```

### **Tema com Animação**
```kotlin
@Composable
private fun AnimatedSunsetBackground() {
    var animationProgress by remember { mutableStateOf(0f) }
    
    LaunchedEffect(Unit) {
        animate(
            initialValue = 0f,
            targetValue = 1f,
            animationSpec = infiniteRepeatable(
                animation = tween(5000, easing = LinearEasing),
                repeatMode = RepeatMode.Reverse
            )
        ) { value, _ ->
            animationProgress = value
        }
    }
    
    Box(
        modifier = Modifier
            .fillMaxSize()
            .background(
                Brush.verticalGradient(
                    colors = listOf(
                        Color(0xFFFF9800).copy(alpha = 0.8f + animationProgress * 0.2f),
                        Color(0xFFE91E63).copy(alpha = 0.6f + animationProgress * 0.4f),
                        Color(0xFF9C27B0).copy(alpha = 0.4f + animationProgress * 0.6f)
                    )
                )
            )
    ) {}
}
```

### **Tema com Padrões Geométricos**

@Composable
private fun GeometricPatternBackground() {
    Canvas(modifier = Modifier.fillMaxSize()) {
        val width = size.width
        val height = size.height
        
        // Desenhar triângulos sobrepostos
        repeat(20) { index ->
            val path = Path().apply {
                moveTo(
                    x = (index * 50f) % width,
                    y = (index * 30f) % height
                )
                lineTo(
                    x = ((index * 50f) + 100f) % width,
                    y = ((index * 30f) + 80f) % height
                )
                lineTo(
                    x = (index * 50f) % width,
                    y = ((index * 30f) + 160f) % height
                )
                close()
            }
            
            drawPath(
                path = path,
                brush = Brush.radialGradient(
                    colors = listOf(
                        Color(0xFF4CAF50).copy(alpha = 0.3f),
                        Color(0xFF4CAF50).copy(alpha = 0.1f)
                    )
                )
            )
        }
    }

## 📱 **MELHORES PRÁTICAS**

### **1. 🎨 Design de Cores**
- ✅ **Use o Material Design 3** como base para consistência
- ✅ **Mantenha contraste adequado** para acessibilidade (mínimo 4.5:1)
- ✅ **Teste em temas claro e escuro** se aplicável
- ✅ **Use ferramentas de contraste** online para validação
- ❌ **Evite cores muito vibrantes** que cansem a vista
- ❌ **Não use cores muito similares** para elementos diferentes

### **2. ⚡ Performance**
- ✅ **Use `remember`** para fundos complexos
- ✅ **Evite animações contínuas** em fundos principais
- ✅ **Otimize gradientes** com cores limitadas (3-5 cores)
- ✅ **Use `alpha` values** para criar variações sem novas cores
- ❌ **Não recrie fundos** a cada recomposição
- ❌ **Não use muitas cores** em um único gradiente

### **3. ♿ Acessibilidade**
- ✅ **Contraste mínimo 4.5:1** para texto normal
- ✅ **Contraste mínimo 3:1** para texto grande
- ✅ **Teste com simuladores** de daltonismo
- ✅ **Considere daltonismo** na escolha das cores
- ✅ **Use ferramentas** como WebAIM Contrast Checker
- ❌ **Não dependa apenas da cor** para transmitir informação

### **4. 🔄 Consistência**
- ✅ **Mantenha padrões visuais** consistentes com o app
- ✅ **Use espaçamentos** padronizados do Material Design
- ✅ **Respeite hierarquia** visual estabelecida
- ✅ **Siga convenções** de nomenclatura existentes
- ❌ **Não quebre convenções** existentes
- ❌ **Não crie padrões** que conflitem com o design system

### **5. 🧪 Teste e Validação**
- ✅ **Teste em diferentes dispositivos** (tamanhos de tela)
- ✅ **Valide em diferentes condições** de iluminação
- ✅ **Teste com usuários** reais se possível
- ✅ **Documente decisões** de design importantes
- ❌ **Não assuma** que funciona só porque compila

## 🔧 **TROUBLESHOOTING**

### **Problema: Tema não é aplicado**
**Solução:**
1. Verifique se o tema foi adicionado à lista `AllThemes`
2. Confirme se o `id` é único
3. Verifique se não há erros de compilação

### **Problema: Fundo não aparece**
**Solução:**
1. Confirme se `LouveTheme.backgrounds.screenBackground()` está sendo chamado
2. Verifique se as telas têm `containerColor = Color.Transparent`
3. Confirme se não há fundos duplicados

### **Problema: Performance degradada**
**Solução:**
1. Use `remember` para fundos complexos
2. Simplifique gradientes com muitas cores
3. Evite animações contínuas desnecessárias

### **Problema: Cores não contrastam bem**
**Solução:**
1. Use ferramentas de contraste online
2. Teste com simuladores de daltonismo
3. Ajuste alpha values para melhor legibilidade

### **Problema: Números de hinos não se adaptam ao tema**
**Sintomas:**
- Números sempre aparecem com cores do tema branco
- Apenas tema escuro funciona corretamente
- Outros temas mostram cores inconsistentes

**Causa:**
- Falta de definição das cores `primaryContainer` e `onPrimaryContainer`
- Material Design usa valores padrão quando essas cores não estão definidas

**Solução:**
```kotlin
// ✅ SEMPRE incluir em todos os temas:
primaryContainer = Color(0xFF...), onPrimaryContainer = Color(0xFF...)
secondaryContainer = Color(0xFF...), onSecondaryContainer = Color(0xFF...)
tertiaryContainer = Color(0xFF...), onTertiaryContainer = Color(0xFF...)
```

**Verificação:**
1. Confirme se todas as cores de container estão definidas
2. Teste em todos os temas disponíveis
3. Verifique se números de hinos se adaptam corretamente
