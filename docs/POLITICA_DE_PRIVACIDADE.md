# Política de Privacidade - Louve App

**Última atualização:** 27 de setembro de 2025

## 1. Introdução

O Louve App ("nós", "nosso" ou "aplicativo") é um aplicativo móvel desenvolvido para facilitar o acesso aos hinos da Harpa Cristã. Esta Política de Privacidade descreve como coletamos, usamos, armazenamos e protegemos suas informações pessoais quando você utiliza nosso aplicativo.

**Responsável pelo tratamento dos dados:** Lucas de Lima  
**Contato:** dev.lucasdelima@gmail.com

## 2. Informações que Coletamos

### 2.1 Dados de Autenticação (Opcional)
Quando você opta por fazer login através do Google Sign-In, coletamos:
- **Nome completo** fornecido pela sua conta Google
- **Endereço de email** da sua conta Google
- **URL da foto de perfil** (se disponível)
- **ID único do usuário** gerado pelo Firebase Authentication

### 2.2 Dados de Preferências do Usuário
- **Hinos favoritos:** Lista dos IDs dos hinos que você marcou como favoritos
- **Configurações de tema:** Tema visual escolhido para personalizar a aparência do aplicativo

### 2.3 Dados de Uso e Analytics
Coletamos automaticamente informações sobre como você usa o aplicativo:
- **Eventos de navegação:** Quais telas você visita
- **Tempo de visualização:** Quanto tempo você passa visualizando cada hino
- **Ações realizadas:** Buscas realizadas, hinos favoritados/desfavoritados
- **Informações técnicas:** Modelo do dispositivo, versão do sistema operacional

### 2.4 Dados Técnicos Automáticos
- **Endereço IP** (coletado automaticamente pelos serviços do Firebase)
- **Identificadores de instalação** para analytics
- **Informações de crash** (se ocorrerem erros no aplicativo)

## 3. Como Usamos suas Informações

### 3.1 Finalidades Principais
- **Funcionalidade do aplicativo:** Permitir que você acesse e personalize sua experiência
- **Sincronização de dados:** Manter seus favoritos e configurações sincronizados entre dispositivos
- **Melhoria do serviço:** Analisar o uso para melhorar a funcionalidade e experiência do usuário

### 3.2 Finalidades Específicas
- **Autenticação:** Verificar sua identidade quando você faz login
- **Personalização:** Aplicar suas preferências de tema e manter sua lista de favoritos
- **Analytics:** Entender como o aplicativo é usado para fazer melhorias
- **Suporte técnico:** Diagnosticar problemas e fornecer assistência

## 4. Por que Coletamos seus Dados

Coletamos suas informações para:

- **Melhorar sua experiência:** Personalizar o app com seus favoritos e preferências
- **Sincronizar entre dispositivos:** Manter seus dados disponíveis em qualquer lugar
- **Entender o uso:** Saber quais funcionalidades são mais importantes para você
- **Manter o app funcionando:** Garantir que tudo funcione perfeitamente

## 5. Compartilhamento de Informações

### 5.1 Serviços de Terceiros
Compartilhamos dados limitados com os seguintes serviços:

**Google (Firebase):**
- Dados de autenticação para login seguro
- Dados de analytics para melhorias do aplicativo
- Dados de preferências para sincronização entre dispositivos

**Firebase Analytics:**
- Dados de uso agregados e anonimizados
- Informações técnicas do dispositivo

### 5.2 Não Compartilhamos
- Não vendemos seus dados pessoais
- Não compartilhamos dados com anunciantes
- Não fornecemos dados para terceiros para fins de marketing

## 6. Armazenamento e Segurança

### 6.1 Localização dos Dados
- **Dados locais:** Armazenados no seu dispositivo usando DataStore
- **Dados na nuvem:** Armazenados no Firebase (Google Cloud) com servidores nos Estados Unidos

### 6.2 Medidas de Segurança
- **Criptografia:** Todos os dados são transmitidos usando HTTPS/TLS
- **Autenticação segura:** Usamos Firebase Authentication com tokens seguros
- **Regras de acesso:** Cada usuário só pode acessar seus próprios dados
- **Backup seguro:** Dados são protegidos pelos sistemas de segurança do Google

### 6.3 Tempo de Retenção
- **Dados de conta:** Mantidos enquanto sua conta estiver ativa
- **Dados locais:** Mantidos no dispositivo até você desinstalar o aplicativo
- **Dados de analytics:** Mantidos por até 26 meses (padrão do Firebase)

## 7. Seus Direitos e Controle

Você tem total controle sobre seus dados:

- **Ver seus dados:** Posso te mostrar exatamente quais informações temos sobre você
- **Corrigir informações:** Se algo estiver errado, posso corrigir rapidamente
- **Remover seus dados:** Se quiser deletar sua conta e todos os dados, posso fazer isso
- **Exportar dados:** Posso te enviar uma cópia de todos os seus dados em formato legível
