# Telemetria de Tarefas — Agentic Skill Squads

Monitoramento das primeiras 20 tarefas executadas pelos agentes.

**Regras:**
- A cada tarefa recebida, o agente executor DEVE registrá-la aqui ANTES de começar.
- Após a conclusão, preencher `Resultado` com base no feedback do HITL code review e validações (tests, build, lint).
- `Resultado = ✅ Sucesso` (aprovado no review + validações OK) ou `❌ Falha` (rejeitado no review ou validação quebrada).
- Máximo de 20 tarefas. Ao atingir 20, parar.
